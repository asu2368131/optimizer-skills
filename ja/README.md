# Optimizer Skills

[英語版](../README.md)

ソフトウェア、自動化、ワークフロー、技術システムを改善するための実践的なスキル集です。各スキルは、性能、信頼性、保守性、セキュリティ、コスト効率、開発者体験などの本質的な改善点を明らかにし、実行しやすい次の手順へ落とし込みます。

最適化自体が目的ではありません。システムの目的、規模、リスクに合う改善を選ぶためのスキルです。

## スキル

| スキル | 対象 |
| --- | --- |
| [`gas-production-readiness-auditor`](skills/gas-production-readiness-auditor/SKILL.md) | Google Apps Script プロジェクトの本番稼働準備状況を監査します。 |
| [`vba-optimizer`](skills/vba-optimizer/SKILL.md) | Excel VBA マクロの速度・正確性・保守性のレビュー。 |

各スキルには、使用すべき場面、評価項目、結果の提示方法が記載されています。

## 使い方

このリポジトリをコーディングアシスタントのスキルソースとして導入し、改善したいシステムや課題について支援を依頼してください。例:

```text
このプロジェクトをレビューし、最も効果の大きい改善点を特定してください。
```

```text
このワークフローの信頼性と保守性を高める方法を教えてください。
```

```text
このコードの性能、セキュリティ、運用上のリスクを分析してください。
```

技術と目的に最も合うスキルを選んでください。各スキルの `SKILL.md` には、固有の起動条件、対象範囲、出力形式が説明されています。

## 導入

リポジトリをクローンし、必要なスキルディレクトリをコーディングアシスタントが使う skills の配置先へ追加してください。各スキルのディレクトリと `SKILL.md` はそのまま保持します。

```bash
git clone https://github.com/asu2368131/optimizer-skills.git
```

正確な skills ディレクトリと導入方法は、利用するアシスタントのドキュメントを参照してください。

## コントリビューション

コントリビューションを歓迎します。新しいスキルは焦点を絞り、実用的なものにし、`SKILL.md` で文書化してください。解決する問題、使用場面、対象とする改善、出力形式を説明してください。
