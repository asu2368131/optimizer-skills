# Optimizer Skills

[English](../README.md)

ソフトウェア、業務自動化、ワークフロー、技術システムを改善するための、実践的なスキル集です。各スキルは、パフォーマンス、信頼性、保守性、セキュリティ、コスト効率、開発者体験などの改善点を見つけ、明確で実行しやすい次のアクションへとつなげます。

このプロジェクトの目的は、最適化そのものではありません。システムの目的、規模、リスクに合った改善を選べるようにすることです。

## スキル

| スキル | 対象 |
| --- | --- |
| [`gas-production-readiness-auditor`](../gas-production-readiness-auditor/SKILL.md) | Google Apps Script プロジェクトの本番運用準備状況を監査します。 |

各スキルには、利用する場面、評価対象、結果の出力形式が個別に記載されています。

## 使い方

このリポジトリをコーディングアシスタントのスキルソースとしてインストールし、改善したいシステムや課題について依頼してください。例:

```text
このプロジェクトをレビューして、最も効果の大きい改善点を特定してください。
```

```text
このワークフローの信頼性と保守性を高める方法を提案してください。
```

```text
このコードのパフォーマンス、セキュリティ、運用上のリスクを分析してください。
```

技術と目的に最も合うスキルを選んでください。各スキルの `SKILL.md` に、具体的な起動条件、対象範囲、出力形式が記載されています。

## インストール

リポジトリをクローンし、利用したいスキルのディレクトリをコーディングアシスタントのスキル用ディレクトリに追加してください。各スキルのディレクトリ名と `SKILL.md` はそのまま保持してください。

```bash
git clone https://github.com/asu2368131/optimizer-skills.git
```

正確なスキル用ディレクトリとインストール方法は、お使いのアシスタントのドキュメントを確認してください。

## コントリビュート

コントリビューションを歓迎します。新しいスキルは対象を明確にし、実用的な内容にしたうえで、`SKILL.md` に記載してください。各スキルが解決する課題、利用する場面、目指す改善、出力形式を説明してください。
